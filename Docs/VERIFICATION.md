# α版の確認結果

確認日: 2026年10月22日（日本時間）

Unity 6000.3.8f1でWindows版のビルド成功。実行版を起動し、48項目の検証と2ステージの通し実行を確認しました。詳細は `Verification/report.json` にあります。

## 確認した内容

- 全5羽の武器が実際に敵へダメージを与えること。
- ペンギンの氷壁が射線を遮り、アルティメットがボスを凍結すること。
- タカのデコイ再発動、壁へのワイヤー、通常射撃の遮蔽とULT射撃の壁貫通。
- カラスのボムとスキルを併用でき、1射につき両方の回数を消費すること。
- フクロウの隕石、3発のULT、上空での無敵、爆風移動。
- ツバメの加速切替、ビームの40ゲージ消費、ULT中にゲージを消費しないこと。
- ダッシュ・ワイヤー・転移・爆風移動で実際の位置が変わること。
- 全員のダウン判定と、12秒後に体力を全回復して復帰すること。
- 操作キャラクターの切替、ポーズでの時間停止、設定画面からの復帰。
- タワーの破壊による敗北、最終ウェーブ掃討による勝利、タイトルへの復帰。

## 通し実行

検証用に全員をAI操作にし、時間を5倍速にしてウェーブ開始から結果まで進めました。ゲーム内の経過時間・ダメージ計算・敵の出現処理は通常と同じです。

ステージAはペンギン・タカ・カラス・フクロウ、ステージBはフクロウをツバメに替えた編成で確認。両方とも最終ウェーブまで進み、防衛成功になりました。各回の撃破数、防衛時間、タワー残量は `report.json` の末尾と結果画面の画像に記録しています。

これは状態遷移と戦闘処理の通し確認です。手動操作の細かな感触、最終的な難易度、外部モデルのアニメーション品質を保証するものではありません。α版として今後調整する範囲です。

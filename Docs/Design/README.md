# 設計資料

[ゲームAI課題制作_設計シート_ex.xlsx](ゲームAI課題制作_設計シート_ex.xlsx) は、前回AIの要件・技術選択を追記したExcelの保存済みファイルを、そのままコピーしてGit管理したものです。4シートと採用した15項目を含みます。

**今後の編集は、このフォルダー内のExcelを開いて保存してください。** Unityプロジェクト外にある元ファイルの編集は、このリポジトリには自動で反映されません。

`.xlsx` はバイナリとしてコミットします。Excelが開いている間にできる `~$` から始まる一時ファイルは除外しています。mapCを追加する今回の作業では、Excelのセル・数式・書式は変更していません。

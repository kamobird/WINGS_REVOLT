# WINGS REVOLT α 0.1

Unity 6000.3.8f1 / URP / Windows

## 起動

完成した実行版は `Builds/Alpha/WINGS_REVOLT_Alpha.exe`。実行ファイルだけを移動せず、同じフォルダーのデータ一式と一緒に扱ってください。

Unityからは `Assets/Wings/Scenes/WingsAlpha.unity` を開いてPlay。`WINGS > Setup Alpha Scene` でシーンと未作成のキャラクター設定を生成できます。既存のキャラクター設定は上書きしません。`WINGS > Build Windows Alpha` はシーンを再生成してWindows実行版を作ります。

## 遊び方

PLAY → ステージA/B → 5羽から4羽を順番に編成 → 出撃。未操作の3羽は自動行動します。タワー耐久値が0になると敗北。最終ウェーブの時間が終わり、残った敵と大型侵攻兵器を倒すと勝利です。途中で倒れた仲間は12秒後にタワー付近で復帰します。

| 操作 | 内容 |
| --- | --- |
| WASD | 視点基準の移動 |
| マウス | 視点・照準 |
| 左クリック | 射撃。カラスは長押しで溜めて離す |
| R | リロード。弾切れでは自動開始 |
| Q | スキル |
| E | ボム。タカは再入力でデコイを竜巻に変化 |
| 左Shift | ムーブ。ツバメは加速のON/OFF |
| Space | ジャンプ |
| X | アルティメット。ゲージ100で発動 |
| 1 / 上矢印 | 編成1番目に切替 |
| 2 / 右矢印 | 編成2番目に切替 |
| 3 / 下矢印 | 編成3番目に切替 |
| 4 / 左矢印 | 編成4番目に切替 |
| 右クリックを長押し＋左クリック | 追従 / タワー防衛 / 攻撃優先の指示 |
| Esc | ポーズ、各画面で戻る |

フクロウのアルティメット中は、左クリックで狙った地点に3発まで爆撃します。タカのワイヤーは25m以内の壁を狙って使用します。ポーズ中は戦闘・効果時間・ウェーブ時間が止まります。指示選択中は戦闘が進みます。

TUTORIALの「実地訓練」ではタワーにダメージが入らず、全員のULTゲージが最初から100になります。

## 旧作資料からの移植

参照資料は接続されたExcel「ドリフトテンプレート - コピー.xlsx」の「概要」「機能一覧表」「フローチャート1/2」「ワイヤーフレーム」「ワイヤーフレーム・インゲーム」。機能一覧のセル本文と、グループ内の図形テキストを確認しました。資料ブック自体は変更していません。

- タイトル → ステージ → 編成 → ロード → 防衛戦 → リザルトの順序を維持。
- タワー、防衛ウェーブ、仲間AI、操作切替、復活、ポーズ、個別の与ダメージ・撃破数を実装。
- DxLib/C++/ini/フレーム単位タイマーを、Unity/C#/ScriptableObject/PlayerPrefs/経過秒に置換。
- 旧作表記の「鷲」は今回の設定の「タカ」に統一。能力・物語は今回提示された5羽の設定を優先。
- 画面端のカーソル移動はUnityのカーソルロックに置換。新Input Systemを使用。
- 元資料に必要編成人数の明記がないため、α版では4方向切替に合わせ4羽。`WingsGame.SquadSize` が定数。
- 右クリックの指示ホイールはα版では3つの指示ボタンとして実装。
- 仮ステージはAが3ウェーブ、Bが4ウェーブ。各38秒、開始待機4秒、次ウェーブ間5秒。最終ウェーブ後に残敵掃討。
- リザルトのS/A/Bは勝利時のタワー残量、C/D/Eは敗北時の到達ウェーブで評価。スコアとステージ別最高点も保存。

## 差し替え・調整

`Assets/Wings/Resources/Characters/*.asset` で各キャラのHP、移動速度、基本ダメージ、連射間隔、ボム・スキル・ムーブの再使用時間、説明文、テーマ色を編集できます。モデルは同じ設定の `Visual Prefab` に指定します。

Prefabの原点は足元、正面はローカル+Z、全体の高さは約1.9m。見た目のPrefabに移動処理やColliderを入れず、当たり判定とゲームロジックは `PlayerAgent` のルートに残してください。アニメーションを追加する際はPrefab側にAnimatorを置き、`PlayerAgent` の状態を読んで遷移させられます。現時点で歩行・攻撃専用のAnimator連携は未実装です。

| ファイル | 担当 |
| --- | --- |
| CharacterDefinition.cs | キャラ設定と初期データ |
| PlayerAgent.cs | 入力、仲間AI、弾数、能力、ダウンと復活 |
| Combat.cs | 敵、飛翔弾、爆発・継続フィールド、デコイ |
| Arena.cs | 仮マップ、遮蔽物、移動の回避誘導 |
| WingsGame.cs | 状態遷移、編成、ウェーブ、タワー、音、保存 |
| WingsUI.cs | 日本語メニューと戦闘HUD |
| WingsVisual.cs | 差し替え前提の仮鳥モデルと簡易エフェクト |
| AlphaVerification.cs | 明示起動した場合だけ走る実行時検証 |
| Editor/AlphaBuilder.cs | シーン生成とWindowsビルド |

## α版の範囲

シングルプレイの防衛プロトタイプです。物語はキャラクター説明に収録し、会話イベントやストーリーミッションはまだ含みません。モデル、背景、敵、UIアイコン、効果音とBGMは仮素材です。音はプログラム生成で、外部のモデル・音楽・音声素材は含めていません。見た目・演出・数値の最終調整、複雑なステージ用のNavMesh移行、キー割当変更、ゲームパッド、オンライン協力は今後の対象です。

## 検証の再実行

実行版に `--wings-smoke --wings-report <出力フォルダー>` を付けると検証モードになります。能力ごとの攻撃・状態・リソース消費、壁貫通、操作切替、ポーズ、勝敗とタイトル復帰を確認し、`report.json` と画面PNGを保存して終了します。通常の起動ではこの検証は動きません。

検証結果は実測後に同梱する `VERIFICATION.md` を参照してください。
